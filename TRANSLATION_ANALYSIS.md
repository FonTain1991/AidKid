## ⚠️ Оставлено без изменений (намеренно)

| Место | Причина |
|-------|---------|
| **Subscription.tsx** — проверка `'Покупка отменена пользователем'` | Сравнение с ответом IAP, нужны оба языка |
| **MedicineForm.tsx** — проверка `'премиум'`, `'лимит'` в ошибке | Анализ текста ошибки от бэкенда |
| **en.ts** — `languageDesc: 'Русский / English'` | Показ названий обоих языков |
| **LocalBackups.tsx, GoogleDriveBackups.tsx** — закомментированный код | Не используется |
| **BarcodeScannerScreen.tsx** — `console.error` | Только для отладки |
| **LimitIndicator.tsx** — JSDoc | Комментарий, не UI |
| **StatisticsScreen.tsx** — комментарий в коде | Не пользовательский текст |

## 📋 Рекомендации

1. **languageDesc** — при добавлении новых языков обновить строку вручную.
2. **Каналы Android** — имена задаются при первом запуске; при смене языка они не обновляются (ограничение Android).
3. **Уведомления о сроке годности** — планируются при добавлении/редактировании лекарства; язык берётся на момент создания.
