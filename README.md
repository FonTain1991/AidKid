# Аптечка 🏥 (AidKit)

Мобильное приложение для управления домашними аптечками, построенное на React Native. Поддержка Android и iOS.

## 📱 О приложении

**Аптечка** — полнофункциональное приложение для организации и отслеживания лекарств в домашних аптечках. Создавайте аптечки, добавляйте лекарства, отслеживайте запасы и сроки годности, настраивайте напоминания и ведите статистику приёма. Поддерживаются русский и английский языки.

### ✨ Реализованные возможности

#### 🏠 Главный экран
- **Поиск** - универсальный поиск по аптечкам и лекарствам
- **Предупреждения** - плашки о лекарствах с истекающим сроком годности и низким запасом
- **Управление аптечками** - создание, редактирование, удаление аптечек
- **Иерархия аптечек** - поддержка вложенных аптечек

#### 💊 Управление лекарствами
- **CRUD операции** - полное управление лекарствами
- **Детальная информация** - название, форма, производитель, дозировка
- **Фото лекарств** - добавление фото упаковки или самого лекарства
- **Штрих-код** - сканирование и сохранение штрих-кодов для быстрого поиска
- **Учет запасов** - количество, единицы измерения, срок годности
- **Цветовое кодирование** - каждая аптечка имеет свой цвет

#### ⏰ Напоминания и прием
- **Напоминания о приеме** - гибкая настройка (один раз, ежедневно, еженедельно)
- **Множественный выбор** - создание напоминаний для нескольких лекарств сразу
- **Отслеживание членов семьи** - указание кто принимает лекарство
- **Экран "Сегодня"** - запланированные приемы на текущий день
- **Быстрый прием** - множественный выбор или мгновенный прием (долгое нажатие)
- **История приема** - полный журнал всех приемов с группировкой по датам
- **Статистика** - анализ приема (сегодня, за неделю, за месяц, топ лекарств)

#### 🔔 Уведомления
- **Push-уведомления** - напоминания о приеме лекарств
- **Уведомления о сроке годности** - за 30, 14, 7, 3, 2, 1 день
- **Настройка разрешений** - проверка и запрос разрешений на Android
- **Иконка уведомлений** - ic_notification с цветом #42A669

#### 📊 Отслеживание и аналитика
- **Истекающие лекарства** - отдельный экран с лекарствами, срок годности которых подходит к концу
- **Низкий запас** - отдельный экран с лекарствами, которые заканчиваются
- **Статистика приема** - динамика, сравнение периодов, топ лекарств
- **История** - все записи о приеме с возможностью удаления

#### 🛒 Список покупок
- **Создание списков** - добавление необходимых лекарств для покупки
- **Фильтрация** - все / не куплено / куплено
- **Напоминания о покупках** - установка даты/времени напоминания с иконкой колокольчика в header
- **Интеграция с аптечкой** - быстрое добавление купленного в аптечку
- **Push-уведомления** - напоминание о походе в аптеку в указанное время

#### 🎓 Onboarding
- **Приветственные экраны** - 6 красивых слайдов при первом запуске
- **Описание возможностей** - знакомство с функциями приложения
- **Навигация** - прокрутка, кнопки "Назад"/"Далее"/"Пропустить"
- **Повторный просмотр** - возможность посмотреть снова через настройки

#### 💧 Трекер воды
- **Персональный учет** - для каждого члена семьи своя норма и статистика
- **Визуальный прогресс** - стакан с водой, заполнение в процентах
- **Быстрые кнопки** - +100мл, +250мл, +500мл или свой объем
- **История** - все приемы воды за день с возможностью удаления
- **Настройки** - персональная дневная норма (по умолчанию 2500мл)
- **Фильтрация** - выбор члена семьи или "Все"
- **Уведомления** - напоминания пить воду с настраиваемым интервалом

#### 🎨 Интерфейс
- **Темная/светлая тема** — переключение между темами
- **Современный дизайн** — Material Design с карточками, тенями, цветовыми акцентами
- **Фото в карточках** — превью фото лекарств во всех списках
- **Иконки** — векторные иконки в нижней навигации
- **Bottom Sheet пикеры** — модальные окна для выбора лекарств
- **Единообразие** — все экраны в едином стиле
- **Офлайн работа** — все данные хранятся локально в SQLite

#### 🌐 Многоязычность (i18n)
- **Русский и английский** — полная локализация интерфейса
- **i18next + react-i18next** — система переводов
- **Автоопределение языка** — по настройкам устройства
- **Переключение в настройках** — смена языка без перезапуска

#### 💎 Премиум подписка (RevenueCat)
- **Бесплатная версия** — лимиты на аптечки, лекарства, напоминания, список покупок
- **Premium** — неограниченные лимиты, облачное резервное копирование, расширенная статистика
- **Проверка обновлений** — уведомление о новой версии в магазине

## 🗄️ База данных

Используется **SQLite** с следующими таблицами:

### Аптечки (`medicine_kits`)
- `id`, `name`, `description`, `color`, `parent_id`
- Поддержка иерархии через `parent_id`

### Лекарства (`medicines`)
- `id`, `name`, `description`, `manufacturer`, `dosage`
- `form`, `prescription_required`, `kit_id`
- `photo_path`, `barcode` - фото и штрих-код лекарства

### Запасы (`medicine_stock`)
- `id`, `medicine_id`, `quantity`, `unit`
- `expiry_date`, `batch_number`, `purchase_date`, `purchase_price`

### Использование (`medicine_usage`)
- `id`, `medicine_id`, `family_member_id`, `quantity_used`, `usage_date`, `notes`

### Члены семьи (`family_members`)
- `id`, `name`, `avatar`, `color` - отслеживание кто принимает лекарства

### Список покупок (`shopping_list`)
- `id`, `medicine_name`, `description`, `is_purchased`, `reminder_date`
- Хранение списка необходимых покупок с возможностью установки напоминания

### Трекер воды (`water_intake`, `water_settings`)
- **water_intake**: `id`, `family_member_id`, `amount`, `intake_time`, `note`
- **water_settings**: `id`, `family_member_id`, `daily_goal`, `reminder_enabled`, настройки напоминаний
- Персональный учет воды для каждого члена семьи

### Справочники
- `medicine_forms` - формы выпуска (таблетки, капли и т.д.)
- `measurement_units` - единицы измерения (шт, мл, г и т.д.)

## 🚀 Быстрый старт

### Требования

- Node.js >= 20
- Yarn или npm
- Android Studio / Xcode (для сборки)

### Установка зависимостей

```sh
# Используя Yarn (рекомендуется)
yarn install

# Или используя npm
npm install
```

### Запуск Metro

```sh
# Используя Yarn
yarn start

# Или используя npm
npm start
```

### Запуск приложения

#### Android

```sh
yarn android
# или
npm run android
```

Сборка release:
```sh
yarn build:android
# или
yarn bundle:android   # AAB для Google Play
```

#### iOS

Сначала установите CocoaPods зависимости:

```sh
cd ios && pod install && cd ..
```

Затем запустите:

```sh
yarn ios
# или
npm run ios
```

## 📱 Экраны приложения

### Основные экраны (Bottom Tabs)
1. **Приём** (takingMedications) — центр управления приёмом лекарств с быстрыми действиями
2. **Аптечки** (medicineKitList) — список аптечек с поиском и предупреждениями
3. **Ещё** (more) — настройки, язык, подписка, резервное копирование

### Экраны аптечек
4. **Kit** - создание/редактирование аптечки с выбором цвета
5. **KitDetails** - детали аптечки со списком лекарств

### Экраны лекарств
6. **Medicine** - создание/редактирование лекарства с запасами
7. **ExpiringMedicines** - лекарства с истекающим сроком годности
8. **LowStockMedicines** - лекарства с низким запасом

### Экраны приема
9. **Today** - запланированные приемы на сегодня
10. **QuickIntake** - быстрая отметка приема
11. **History** - история всех приемов с группировкой по датам
12. **Statistics** - статистика и аналитика приема

### Экраны напоминаний
13. **Reminders** - список активных напоминаний
14. **AddReminder** - добавление нового напоминания с множественным выбором

### Экраны списка покупок
15. **ShoppingList** - список покупок с фильтрацией и напоминаниями
16. **AddShoppingItem** - добавление товара в список

### Прочие экраны
17. **Onboarding** — приветственные экраны при первом запуске (6 слайдов)
18. **Splash** — экран загрузки (react-native-bootsplash) и инициализация БД
19. **NotificationSettings** — настройки уведомлений
20. **FamilyMembers** — управление членами семьи
21. **FamilyAccess** — доступ семьи и семейные группы
22. **BarcodeScanner** — сканирование штрих-кодов лекарств
23. **Backup** — резервное копирование (локальные бэкапы + Google Drive)
24. **Subscribe / Subscription** — экраны премиум подписки
